# F10 — H5: Media library beats compositor migration

**Status:** CONFIRMED (with nuance)  
**Sources:** 01, 03, 12, 14, 20, 28, 06, 32 | opposition 29, 30

## Thesis

For ShadowCast’s kinetic affiliate assemble pipeline over the next 1–2 quarters, stocking/licensing music, B-roll, and product stills (and making them easy to use) raises mainstream CTR more than migrating MoviePy → Remotion.

## Evidence

- Local readiness: mainstream ~75%, ceiling is operator media, not missing code (01).
- Template vs AI: variant-heavy deterministic assembly is cheaper and claim-safer (14).
- Remotion justified for React multi-brand design systems — not Python single-brand Shorts (12, 28).
- Stock B-roll + slides beat cinematic cuts for conversion in VSL-adjacent tests (20).
- MoviePy is slower than ffmpeg but remains correct for text overlay automation (06, 32); NVENC accelerates encode without rewrite (13).

## Nuance / insufficient absolute

- Media *accessibility* can fake a scarcity ceiling (29) — still a media-ops problem, not Remotion.
- Talking-head affiliate formats can outperform kinetic in some niches (30) — product-class change, watch-list.

## Implication

P0 backlog: operator media pack + fetch scripts + readiness gate on real beds/stills. Do not start Remotion.
